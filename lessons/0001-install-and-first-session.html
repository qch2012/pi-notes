Lesson 0001 · Getting started

Install Pi, authenticate, run a first session

You already know the shape of a terminal coding agent. This lesson is just Pi's specific commands, plus the handful of places it deliberately does less than what you're used to.

Why this lesson Your mission is to daily-drive Pi. Step one is mechanical: get it installed, authenticated, and running on a real project — and know, going in, the four defaults it ships with and the six things it leaves out.

1. Install

Pi ships on npm as a global package:

npm install -g --ignore-scripts @earendil-works/pi-coding-agent

--ignore-scripts just skips dependency lifecycle scripts — they're not needed for normal operation. Uninstalling later (any package manager) keeps your settings and credentials in ~/.pi/agent/, so reinstalling doesn't mean re-authenticating.

2. Authenticate

Two paths, pick whichever matches how you already pay for a model:

  • Subscription — run /login inside Pi once it's running. Works with Claude Pro/Max, ChatGPT Plus/Pro, or GitHub Copilot.
  • API key — export ANTHROPIC_API_KEY=sk-ant-... before launch, or run /login to store a key persistently in ~/.pi/agent/auth.json.

3. Launch, in a real project

cd /path/to/project
pi

That's it — no separate init step. Once it's up, give it something real rather than a toy prompt, e.g. "Summarize this repository and tell me how to run its checks."

4. The default toolset is smaller than you're used to

Pi gives the model exactly four tools out of the box:

ToolDoes
readRead files
writeCreate or overwrite files
editPatch files
bashRun shell commands

No built-in web search, no built-in MCP client — those exist as extensions/packages you opt into, not defaults you opt out of.

5. Six things Pi intentionally doesn't do by default

This is the part most likely to trip you up coming from a heavier daily driver. Pi's docs state this explicitly as a design choice, not a gap:

  • No built-in MCP
  • No sub-agents
  • No permission popups — bash runs without a per-call confirmation prompt
  • No plan mode
  • No to-do / task tracking
  • No background bash

All six are addable as extensions if you end up wanting them back — that's a later lesson, once Skills/Extensions are in your zone of proximal development.

6. Good news: your context files already work

Pi auto-loads AGENTS.md, CLAUDE.md, or AGENTS.override.md from global settings, parent directories, and the current working directory. Whatever project conventions you've already written for other agents, Pi reads on day one.

Retrieval check — no peeking until you've tried
