Install / uninstall

npm install -g --ignore-scripts @earendil-works/pi-coding-agent

--ignore-scripts skips dependency lifecycle scripts — not needed for normal operation.

ManagerUninstall
npmnpm uninstall -g @earendil-works/pi-coding-agent
pnpmpnpm remove -g @earendil-works/pi-coding-agent
Yarnyarn global remove @earendil-works/pi-coding-agent
Bunbun uninstall -g @earendil-works/pi-coding-agent

Settings and credentials persist in ~/.pi/agent/ across uninstall.

Auth

  • /login inside Pi — subscription (Claude Pro/Max, ChatGPT Plus/Pro, GitHub Copilot) or to store an API key persistently in ~/.pi/agent/auth.json
  • Env var before launch: export ANTHROPIC_API_KEY=sk-ant-...

Default toolset

Unlike agents with a large built-in tool surface, Pi ships exactly four tools by default:

ToolDoes
readRead files
writeCreate or overwrite files
editPatch files
bashRun shell commands

Everything else — web search, MCP servers, structured task tracking — is added via extensions, not baked in.

What Pi omits by default

Deliberately excluded from core, implementable as extensions/packages if wanted:

  • Built-in MCP client
  • Sub-agents
  • Permission popups (bash runs without a per-call confirmation prompt)
  • Plan mode
  • To-do / task tracking
  • Background bash

Context files

Pi auto-loads, from global settings, parent directories, and cwd: AGENTS.md, CLAUDE.md, AGENTS.override.md.
